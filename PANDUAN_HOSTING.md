# Panduan Hosting dengan Coolify Lokal dan Cloudflare Tunnel

Ide utamanya sebenarnya sangat masuk akal. Daripada menyewa VPS mahal di luar sana, laptop atau komputer Anda sendiri bisa disulap jadi server gratisan. Coolify bertugas sebagai manajer yang mengurus Docker dan aplikasi mirip seperti Vercel atau Heroku. Masalahnya jaringan internet rumahan biasanya tidak punya IP Publik statis dan sering terhalang sistem NAT dari provider. Cloudflare Tunnel hadir tepat untuk mendobrak dinding itu. Alat ini membuka terowongan aman dari mesin lokal Anda langsung ke jaringan global Cloudflare tanpa perlu repot membuka *port* di router. Menarik, kan.

Langkah awalnya dimulai dari pihak Cloudflare. Anda wajib punya nama domain aktif yang DNS-nya dikelola lewat akun Cloudflare. Masuk ke dasbor utama lalu cari menu Zero Trust. Telusuri bagian Networks dan temukan opsi Tunnels. Buat tunnel baru di sana. Sistem akan memberi Anda sebuah token panjang atau perintah khusus untuk dieksekusi nanti. Simpan perintah itu baik-baik.

Bergeser ke mesin lokal Anda yang menjalankan Linux CachyOS. Buka terminal dan eksekusi skrip instalasi resmi Coolify menggunakan perintah curl yang ada di situs web mereka. Biarkan prosesnya berjalan karena ini memakan waktu lumayan lama untuk mengunduh semua wadah Docker yang dibutuhkan. Begitu selesai, dasbor Coolify langsung bisa diakses lewat browser di alamat localhost dengan port 8000. Buat akun admin pertama Anda di sana.

Sekarang waktunya menyambungkan jembatan. Instal paket `cloudflared` di Linux Anda. Jalankan perintah token yang Anda simpan dari dasbor Zero Trust tadi di terminal. Terowongan otomatis terbentuk. Kembali ke layar Cloudflare lalu arahkan rute *Public Hostname* (misalnya dasbor.domainanda.com) menuju ke layanan lokal `http://localhost:8000`. Dalam hitungan detik, dasbor Coolify Anda sudah bisa diakses dari ujung dunia manapun lewat internet.

Urusan terakhir tinggal memasukkan proyek *dashboard* ini ke dalam Coolify. Di dasbor Coolify, pilih opsi untuk menambahkan sumber daya baru. Tarik kode proyek ini dari repositori Git atau gunakan pengaturan Docker Compose yang sudah kita buat sebelumnya. Tentukan nama domain publik untuk aplikasi ini (misalnya app.domainanda.com). Jangan lupa masuk lagi ke Cloudflare Tunnel untuk menambahkan rute baru yang mengarahkan domain aplikasi tersebut ke port internal Docker tempat proyek ini berjalan (port 3000). Selesai.
